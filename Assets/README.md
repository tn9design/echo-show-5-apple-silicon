# EchoGuide app icon

`EchoGuide-icon.png` is original artwork generated with the built-in image-generation tool. `EchoGuide.icns` is the standard macOS icon family made from it with `bash script/build-icon.sh`; conversion uses Apple's `sips` and `iconutil`. Preserve the transparent outside margin.

Prompt: Create one polished original macOS app icon for EchoGuide, a local tool helping people install alternative software on a small smart display. Square composition, premium softly sculpted 3D style, a compact charcoal smart display viewed nearly front-on with a luminous teal guiding path/arrow on its screen suggesting a fresh start. Simple bold silhouette legible at 32px, subtle depth and restrained highlights, no text, no logos, no robot mascot, no extra objects. Centered inside a rounded-square deep midnight blue tile, generous icon-safe margins, transparent outside tile. App icon asset only, no mockup, no desktop or dock.

The preview packaging now includes the icon. Its appearance in the running Dock still requires visual verification.
